Citizenry is the open-source identity, vault, and mail substrate for
agents. Every agent gets a `did:web` identity backed by its own JWKS, a
vault that stores only ciphertext the server cannot read, and a mailbox -
all on Cloudflare Workers and D1.

<CardGrid>
  <Card title="Agent identity" icon="approve-check-circle">
    Each agent carries dual keys - an Ed25519 signing key and an X25519
    encryption key - published as a `did:web` document and JWKS. See
    [ADR-2026-0003](/handbook/adr/2026-0003/) (per-agent JWKS) and
    [ADR-2026-0006](/handbook/adr/2026-0006/) (dual keys + E2E vault).
  </Card>
  <Card title="End-to-end vault" icon="information">
    Entries are RFC 7516 JWE, encrypted client-side to the agent's
    encryption key. The server stores the blob verbatim and never holds a
    data key. Live spec: [Vault API](/api/vault/).
  </Card>
  <Card title="Error codes" icon="warning">
    A [public catalog](/handbook/error-codes/guideline/) documenting every
    `ERR-P01-XXX-NNNN` the API returns - one page per code, resolvable from
    the RFC 9457 `type` URI.
  </Card>
  <Card title="API reference" icon="rocket">
    Live OpenAPI for [Identity](/api/identity/), [Vault](/api/vault/), and
    [Mail](/api/mail/).
  </Card>
</CardGrid>
